# Project Overview

GenesisEngine is a C++20 engine/editor workspace targeting Windows, MSVC, SDL2, Vulkan, ImGui, Assimp, fmt, EnTT, and vk-bootstrap.

The workspace is generated by Premake. The generated Visual Studio solution and project files are local artifacts and are ignored by git.

## Repository Layout

| Path | Role |
| --- | --- |
| `premake5.lua` | Root Premake workspace definition. |
| `premake_cfg.lua` | Shared path, include directory, library directory, and third-party library configuration. |
| `Engine.lua` | Premake project definition for the `Engine` shared library. |
| `Editor.lua` | Premake project definition for the `Editor` executable. |
| `Assimp.lua` | Utility Premake project that drives CMake for Assimp. |
| `Engine/` | Engine runtime, public API headers, renderer, assets, ECS, systems, windowing, input, GUI, and utilities. |
| `Editor/` | Editor entry point, editor camera, ImGui editor windows, and test/editor systems. |
| `Resources/` | Runtime resources such as shaders and fonts. |
| `vendor/` | Third-party dependencies tracked as git submodules. |

## Workspace Projects

### Engine

`Engine` is configured as a shared library. It includes the engine source tree, ImGui source files, ImGui Vulkan/SDL backends, and vk-bootstrap source files. It links against SDL2, Vulkan, Assimp, and fmt.

Important source areas:

- `Engine/API/`: public umbrella headers for applications using the engine.
- `Engine/Core/`: entities, handles, components, camera, and screen helpers.
- `Engine/Systems/`: base system type and global system manager.
- `Engine/Renderer/`: render system, renderer facade, render graph, Vulkan resources, and Vulkan backend.
- `Engine/Object/`: engine-side asset/object types.
- `Engine/Assets/`: Assimp and STB-based asset loading.
- `Engine/Window/`: SDL window ownership and window system.
- `Engine/Gui/`: ImGui backend and base GUI window.
- `Engine/Input/`: SDL input polling and frame input state.
- `Engine/Utils/`: path, time, random, and filesystem helpers.

### Editor

`Editor` is configured as a console application that links against `Engine.lib`. It creates an engine instance, registers editor-specific systems, and registers ImGui windows.

The editor currently registers:

- `TestSystemExternal`
- `EditorCameraSystem`
- `DockingRoot`
- `SceneViewWindow`
- `IconBrowserWindow`
- `TestEditorWindow`

### Assimp Utility

The `assimp` Premake project is a utility target. It creates the Assimp build directory, runs CMake, builds Assimp in Release configuration, and copies the resulting binaries into the output directory.

## Third-Party Dependencies

The tracked submodules are:

- `vendor/fmt`
- `vendor/vk-bootstrap`
- `vendor/ImGui` on the `docking` branch
- `vendor/entt`
- `vendor/assimp`

The configuration also references optional or currently commented dependencies such as yaml-cpp, ImGuizmo, spirv_reflect, and SPIRV-Cross.

## Generated and Local Artifacts

The `.gitignore` excludes generated Visual Studio files, `bin`, `bin-int`, `.vs`, and `.dotnet-home`. Local generated files may still exist in a working tree, but they are not part of the tracked source surface.
